# Documentación

- `product/`: visión y requisitos del producto.
- `domain/`: subdominios OPEC, aprendizaje y jurídico.
- `architecture/`: arquitectura y modelo integrado.
- `decisions/`: decisiones arquitectónicas aceptadas.
- `execution/active/`: planes de ejecución vigentes.
- `testing/`: criterios de aceptación.

Las fuentes jurídicas controladas y especificaciones operativas viven en `specs/` en la raíz del repositorio.
