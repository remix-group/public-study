# MVP Requirements

## FR-001
El usuario puede seleccionar una competencia.

## FR-002
El sistema puede mostrar los objetivos de aprendizaje de la competencia.

## FR-003
El usuario puede estudiar un objetivo.

## FR-004
El sistema puede mostrar evidencia jurídica relacionada.

## FR-005
El sistema puede presentar preguntas únicamente cuando todas sus fuentes jurídicas oficiales estén vigentes y aprobadas.

## FR-006
El sistema puede registrar respuestas.

## FR-007
El sistema puede evaluar respuestas.

## FR-008
El sistema puede registrar errores.

## FR-009
El sistema puede actualizar el dominio del estudiante.

## FR-010
El sistema puede programar una revisión posterior.

## FR-011
El sistema puede presentar un caso situacional, registrar el análisis escrito del estudiante y contrastarlo con una referencia editorial y fuentes trazables sin atribuir una calificación automática al texto abierto.

## FR-012
El sistema puede mostrar el progreso.

## FR-013
La generación asistida por IA debe producir borradores. No puede aprobar unidades jurídicas, publicar documentos ni habilitar preguntas automáticamente.

## FR-014
El usuario puede consultar el material documental pendiente de revisión con una advertencia explícita, sin que ese material habilite práctica evaluable.
