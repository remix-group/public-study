# MVP Requirements

## FR-001
El usuario puede seleccionar una competencia.

## FR-002
El sistema puede mostrar los objetivos de aprendizaje de la competencia.

## FR-003
El usuario puede estudiar un objetivo.

## FR-004
El sistema puede mostrar evidencia jurídica relacionada.

## FR-005
El sistema puede presentar preguntas.

## FR-006
El sistema puede registrar respuestas.

## FR-007
El sistema puede evaluar respuestas.

## FR-008
El sistema puede registrar errores.

## FR-009
El sistema puede actualizar el dominio del estudiante.

## FR-010
El sistema puede programar una revisión posterior.

## FR-011
El sistema puede presentar un caso situacional.

## FR-012
El sistema puede mostrar el progreso.
