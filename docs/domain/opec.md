# Equivalencia con JobProfile

La entidad `OPEC` representa el `JobProfile` de la experiencia de aprendizaje. Conserva
el identificador de la vacante, nivel, proceso y subproceso que condicionan el currículo.
La jerarquía curricular es `OPEC -> Competency -> Block -> Topic -> LearningObjective`.

## Ruta integral aportada

La ruta de preparación de la OPEC 236828 se representa como una competencia curricular
integral con seis bloques y veinticinco temas. Esta agrupación permite conservar literalmente
el orden de estudio aportado sin crear una entidad de dominio paralela. Las competencias
funcionales específicas continúan siendo la referencia semántica del perfil; la competencia
integral funciona como proyección navegable para el estudiante.
